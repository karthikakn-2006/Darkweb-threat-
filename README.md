## 🎯 Problem Statement

Threat actors can use:

- Multiple usernames
- Fake identities
- PGP keys
- Cryptocurrency wallets
- Dark Web accounts
- Domains
- Infrastructure
- AI-generated text

to separate their activities across different platforms.

Traditional investigations may analyze these indicators individually.

DARKTRACE proposes a **multi-signal graph-fusion approach** that combines these observations and presents potential relationships with confidence scores and supporting evidence.

🔐 Security & Ethical Guidelines

DARKTRACE follows an evidence-centric approach.

Tor usage ≠ criminal activity

PGP match ≠ identity proof

Wallet relationship ≠ ownership proof

IP relationship ≠ person identification

Stylometry match ≠ definitive authorship

AI prediction ≠ evidence by itself

The investigation process should be:

Observed
   ↓
Correlated
   ↓
Scored
   ↓
Explained
   ↓
Human Review

Only public, synthetic or properly authorized information should be used.
